# Quran Reels Studio — أداة إنشاء فيديوهات القرآن

برنامج محلي مفتوح المصدر من [TechMouad](https://techmouad.com) يجمع خلفية فيديو مع تلاوة حقيقية ونص الآيات بالعربية وترجمة اختيارية لمعانيها. لا يحتاج إلى مفتاح OpenAI أو توليد صوت بالذكاء الاصطناعي.

## ما الذي تحتاجه؟

- Python 3.11 أو أحدث.
- FFmpeg وffprobe متاحان في PATH.
- مفتاح Pexels أو Pixabay عند اختيار خلفية من الإنترنت. إذا رفعت فيديو تملكه فلا تحتاج إلى أي مفتاح API.
- اتصال بالإنترنت لتحميل النص والتلاوة من AlQuran Cloud.

## التشغيل في Windows

حمّل المستودع وفك الضغط. بعد تثبيت Python وFFmpeg، افتح `start-windows.bat`. أو افتح PowerShell داخل مجلد المشروع:

```powershell
python -m venv .venv
.venv\Scripts\python.exe -m pip install -e .
.venv\Scripts\python.exe -m quran_reels.setup_windows
.venv\Scripts\python.exe -m streamlit run app.py
```

تظهر الواجهة في المتصفح على `http://127.0.0.1:8501`. الواجهة الحالية بالإنجليزية، وتدعم عرض القرآن بالعربية من اليمين إلى اليسار.

في Windows x64 يثبت أمر setup_windows مكتبة FriBiDi اللازمة لتشكيل العربية داخل البيئة المحلية، إذا كانت غير متاحة. ينزّل حزمة ثابتة من conda-forge ويتحقق من بصمتها ويحفظ رخصتها مع المكتبة. ينفذ ملف التشغيل هذه الخطوة تلقائياً. إذا تعذر تحميل المكتبة، راجع قسم Windows في README أو استخدم Docker.

## إنشاء الفيديو

1. اختر Pexels أو Pixabay وأدخل مفتاحك في الحقل المخفي، أو اختر My own video وارفع خلفيتك.
2. حدد السورة وأول وآخر آية والقارئ والترجمة والمقاس.
3. اضغط Load passage for review لقراءة النص والاستماع إلى التلاوة.
4. بعد مراجعة النص، فعّل مربع التأكيد واضغط Generate video.
5. شاهد الفيديو كاملاً ثم نزّل MP4 أو ملف ZIP الذي يضم الفيديو والمصادر والاعتمادات.

ابدأ بسورة الإخلاص، الآيات 1–4، وصيغة Portrait 720p. يجب أن تكون الخلفية أطول من التلاوة. لا يكرر البرنامج الخلفية ولا يقطع التلاوة لتناسبها.

يتغير النص عند حدود الآيات وفق عدد عينات الصوت بعد فك التسجيل. لا توجد مزامنة لكل كلمة. إذا لم تلائم الآية الطويلة مساحة النص المقروءة يتوقف التصدير، ويمكن تجربة المقاس العمودي أو إلغاء الترجمة.

يحفظ البرنامج النتائج في `output/`، ولا ينشرها في حسابات التواصل. راجع الآيات والصوت والخلفية وحقوق استخدام التسجيل والترجمة قبل النشر. لا تضع مفاتيحك في GitHub.

للتفاصيل والأوامر وDocker والحدود المعروفة، راجع [README الرئيسي](../README.md).
